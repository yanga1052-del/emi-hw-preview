3 관련문제 풀이 · 4문항

1. 다음 중 x에 대한 항등식인 것은? [항등식의 뜻]
정답 ②. 항등식은 x에 어떤 값을 넣어도 항상 성립하는 등식. ②는 우변을 전개하면 x2−1 로 양변이 완전히 같습니다. ①은 x=±1, ④는 x=0, ⑤는 x=0,±1에서만 성립, ③은 전개하면 2x 만큼 차이가 나 성립하지 않습니다.
2. 등식 a(x+1)2 + b(x+1) + c = x2 + 3x + 4 가 x에 대한 항등식일 때, a2+b2+c2 의 값은? [계수비교법]
정답 ④. 좌변을 전개하면 a x2 + (2a+b)x + (a+b+c). 계수를 비교하면 a=1, 2a+b=3 → b=1, a+b+c=4 → c=2. 따라서 a2+b2+c2 = 1+1+4 = 6.
3. 다항식 (1+2x)4 = a0 + a1x + a2x2 + a3x3 + a4x4 일 때, a0+a1+a2+a3+a4 의 값은? [수치대입법]
정답 ③. 모든 계수의 합은 항등식에 x=1 을 대입하면 바로 나옵니다. (1+2·1)4 = 34 = 81.
4. 위 (1+2x)4 의 전개에서 홀수차항의 계수의 합 a1+a3 의 값은? [수치대입 활용]
정답 ①. x=1 대입 f(1)=81, x=−1 대입 f(−1)=(1−2)4=1. 홀수차항 계수의 합 = (f(1)−f(−1))/2 = (81−1)/2 = 40.
